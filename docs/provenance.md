## Bridge implementation

The transport, local JSONL adapter, task controls, and tests are maintained as
JavaScript in this repository. It communicates with a separately installed
Multica deployment over HTTP and reads local Codex metadata/JSONL files. It does
not vendor Multica's server, daemon, CLI, UI, enterprise directories, or Codex.
No product logos or screenshots are shipped. Product names identify compatibility.

During earlier private development, Multica source was consulted to understand
API behavior, permissions, and redaction. That reference history is disclosed;
removing private Git history does not erase any copyright obligations. Reviewers
must not interpret this snapshot as a clean-room certification. In particular,
rewording or translating third-party implementation is not sufficient to avoid
its license. Later contributions must record any copied/adapted source explicitly.

## Credential-format rules

The rule subset in `src/secret-patterns.mjs` is adapted from the MIT-licensed
[Gitleaks default rules](https://github.com/gitleaks/gitleaks/blob/5f6ec56cfa6f8c67648d863582c7ae2f206d5c1c/config/gitleaks.toml)
at commit `5f6ec56cfa6f8c67648d863582c7ae2f206d5c1c`.
The original [MIT license](../licenses/GITLEAKS.txt), copyright 2019 Zachary Rice,
is distributed verbatim; attribution is also in [NOTICE](../NOTICE).

The selected families are github-pat, github-fine-grained-pat, gitlab-pat,
aws-access-token, openai-api-key, anthropic-api-key, slack-app-token,
slack-bot-token, slack-user-token, stripe-access-token, gcp-api-key, jwt, and
private-key. JavaScript adaptations broaden several prefixes and lengths,
remove entropy/context constraints, and mask incomplete PEM blocks. They are
intentionally not equivalent to Gitleaks detection, its full rule database, or
its validation guarantees. No Gitleaks runtime is required.

Generic key-name redaction, field traversal, exact matching of the already-loaded
login token, local path masking, and protocol-specific token prefix matching are
implemented by the bridge. Multica implementation files are not embedded in the
public rule module.

## Dependencies and runtimes

`package-lock.json` pins the Node dependency graph. `THIRD_PARTY_NOTICES.md`
contains the license texts found in every installed locked package and is
regenerated by `npm run licenses`. The direct dependencies are the MIT-licensed
MCP TypeScript SDK and Zod. Node.js, Multica, and Codex are separate prerequisites,
not redistributed components. Their own licensing and service terms still apply.
