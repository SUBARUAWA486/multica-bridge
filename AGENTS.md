Apply this to creation and updates. Do not add acceptance/scope sections or rewrite existing descriptions automatically.

The model may independently choose only in_progress and in_review. New tasks default to low priority. Use another priority, or change an existing task priority, only when the user explicitly specifies it; do not infer urgency from task content.

This selects one project-area label alongside a task-nature label. Do not re-prompt for existing-task association or resume. Honor an explicit user request to leave the label unset.
